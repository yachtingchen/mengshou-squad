# 萌獸小隊｜英文字母魔法卡牌對戰

走進字母森林，聽怪物的英文名字，再用字母魔法卡把牠變成星光。繁體中文介面、原創 SVG 插畫、真人短音檔，適合 4～6 歲。

純靜態 HTML / CSS / JavaScript，沒有建置步驟、npm 依賴或後端。圖片、音訊與字型皆不需外部服務；下載完整 repo 後可離線遊玩。

## 怎麼玩

1. 選「第 1 階段：認識字母」或「第 2 階段：聽音辨字」。預設進入第 1 階段。
2. 點怪物或「再聽一次」，聽單字與開頭音，例如 `apple → /æ/ → /æ/ → apple`。初次開頁請先點一下並開啟裝置聲音。
3. 點卡牌下方「聽字母」，分開聽字母名與開頭音；點大字母卡就施法。
4. 選錯可再選，沒有扣血或倒數。選對後怪物變成星光，出現完整發音關聯，按「下一隻怪物」繼續。
5. 打敗 5 隻即完成，可重玩或切換階段；切換階段會重新從 0/5 開始。

第 1 階段顯示單字，從兩張卡選一；第 2 階段打亂怪物順序，答對前隱藏單字，從三張卡選一。每階段包含 A/a–apple、B/b–ball、C/c–cat、D/d–dog、E/e–egg。

字母名與自然發音分開處理：A 的字母名是 /eɪ/，apple 的開頭音是 /æ/。答對後會聽到 `A! A says /æ/ in apple!`，並看到字母外形、字母名、開頭音、單字。C 在 cat 中發 /k/。這些是當前單字的開頭音，並非字母所有可能的發音。

第 3 階段、卡牌升級、圖鑑收藏未實作；完整 MVP 規則見 [GAME_RULES.md](GAME_RULES.md)。

## 本地開啟

直接用現代瀏覽器開啟根目錄 `index.html` 即可，請保留 `assets/` 及同目錄的 CSS、JS。也可以啟動簡單伺服器：

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。手機／平板可使用瀏覽器；遊戲支援觸控、鍵盤與系統「減少動態效果」設定。「音效：開／關」只切換戰鬥音效，教學重聽保持可用。

根目錄就是網站成品；所有資源使用相對路徑，適合上述子目錄。保留現有 GitHub Pages 發佈設定；若使用分支發佈，選取原本的發佈分支及 `/ (root)`。由儲存庫擁有者提交、推送後觸發原本部署流程即可，本次只修改工作區，沒有推送、變更 remote 或新增部署服務。

`staticwebapp.config.json` 保留原樣，之後也可繼續用 Azure Static Web Apps，app location `/`、無 API、無建置輸出、`skip_app_build: true`。

## 圖片與音訊

- 五隻怪物、分層森林背景與魔杖均為專為本遊戲繪製的 SVG，縮放清楚，沒有 emoji 拼貼或外部圖庫依賴。
- `assets/audio/` 內含 17 個真人短 MP3（約 170 KiB）。字母名與 IPA 音素使用不同錄音，分段播放、保留間隔、統一響度；不依賴 Web Speech API 的 voice 是否可用，也不把音標直接交給 TTS。
- 錄音取自 Wikimedia Commons，以 CC BY-SA 3.0 或公有領域提供。加工後音檔保留對應授權；各錄音由不同講者提供，音色略有差異。B/C/D 採短子音示範，未刻意拉長或另加母音。詳見 [素材來源與加工聲明](assets/CREDITS.md) 和網站的 [來源頁](credits.html)。
- 選卡、選錯、命中與通關音效以 Web Audio 合成。瀏覽器首次需使用者操作才能開始播音；若裝置靜音或拒播，請開啟聲音後重聽。
- 選卡、施法飛行、受擊消失、進度慶祝與答錯輕抖約 300～900 ms；減少動態效果時切為短暫靜態回饋。

## 檔案與測試

- `index.html`：入口、教學說明視窗。
- `game.js`：純函式規則、階段、卡牌、判定與進度。
- `app.js`：畫面與動畫流程；切換時取消舊回呼。
- `audio.js`：本地真人語音序列、取消與錯誤處理、合成音效。
- `style.css`、`assets/art/`：響應式畫面與原創插畫。
- `tests/game.test.js`：Node 內建測試，不需安裝任何套件。

```bash
node tests/game.test.js
```

瀏覽器驗收還包含桌機／手機排版、兩階段各五隻通關、子路徑資源、直接開檔、離線錄音、減少動態效果與中途切換階段。實際測試結果見 [codex-last.txt](codex-last.txt)。
